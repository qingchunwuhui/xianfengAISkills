# 任务执行模板 (Task Execution Template)

此模板用于 `task-start` 技能在任务启动时自动生成实战执行文档。

---

## 模板规范

```markdown
---
type: 实战执行
task_type: {Bug修复 | 新功能开发 | 配置部署 | 性能优化 | 需求调研}
status: 进行中
start_date: {YYYY-MM-DD}
completion_date:
tags:
  - 实战记录
  - {任务相关标签}
---

# {YYYY-MM-DD}-实战-{任务名称}

## 📋 任务目标 (Goal)

**要解决的问题**：
[一句话描述任务目标]

**验收标准 (Acceptance Criteria)**：
- [ ] 标准1
- [ ] 标准2
- [ ] 标准3

**预计时间**：{预估}
**实际时间**：{事后填写}

## ✅ 执行清单 (Execution Checklist)

{根据任务类型，动态填充对应的清单}

### Bug修复清单
- [ ] 1. 复现问题（截图/录屏保存）
- [ ] 2. 定位根因（查看日志/断点调试）
- [ ] 3. 提出假设（为什么会出现这个问题？）
- [ ] 4. 验证假设（测试假设是否正确）
- [ ] 5. 实施修复（代码修改）
- [ ] 6. 回归测试（确保修复生效且无副作用）

### 新功能开发清单
- [ ] 1. 需求确认（明确验收标准）
- [ ] 2. 技术方案设计（架构/接口/数据结构）
- [ ] 3. 接口设计（API定义/参数/返回值）
- [ ] 4. 编码实现（核心逻辑）
- [ ] 5. 单元测试（覆盖核心逻辑）
- [ ] 6. 集成测试（端到端验证）

### 配置部署清单
- [ ] 1. 环境检查（版本/依赖确认）
- [ ] 2. 配置文件准备（备份原配置）
- [ ] 3. 执行部署命令（记录完整命令）
- [ ] 4. 验证部署结果（功能测试）
- [ ] 5. 回滚方案准备（如果失败如何恢复）

### 性能优化清单
- [ ] 1. 性能基准测试（优化前数据）
- [ ] 2. 性能瓶颈分析（定位慢在哪里）
- [ ] 3. 优化方案设计（技术方案）
- [ ] 4. 实施优化（代码修改）
- [ ] 5. 性能对比测试（优化后数据）

### 需求调研清单
- [ ] 1. 明确调研目标（要回答什么问题？）
- [ ] 2. 信息收集（文档/代码/咨询专家）
- [ ] 3. 方案对比（列出2-3个可选方案）
- [ ] 4. 结论与建议（最终选择哪个？为什么？）
```

## 使用说明

1. **任务启动时**：使用 `/task-start` 生成此文档
2. **执行过程中**：对照执行清单，实时填写日志和问题记录
3. **任务完成后**：填写复盘思考，检查是否需要提取资产
4. **后续处理**：
   - 如需转化为标准实战笔记 → 使用 `/note`
   - 如需提取通用资产 → 使用 `/kn`
