## ✅ 执行清单 (Execution Checklist)

- [ ] 1. 复现问题（截图/录屏保存）
- [ ] 2. 定位根因（查看日志/断点调试）
- [ ] 3. 提出假设（为什么会出现这个问题？）
- [ ] 4. 验证假设（测试假设是否正确）
- [ ] 5. 实施修复（代码修改）
- [ ] 6. 回归测试（确保修复生效且无副作用）
